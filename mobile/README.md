# Omnira mobile

Flutter Android/iOS entrypoint. Shared UI, API, SQLite and synchronization live in `../packages/omnira_app`.

From the project root run `python3 tools/bootstrap_flutter.py --target mobile`, then read `../SETUP.md` for Android/iOS build requirements and `API_BASE_URL`. The platform runners are generated with your installed Flutter SDK. This source delivery does not contain a prebuilt APK/IPA.
