# Mobile setup

This folder contains the Flutter app source and assets. Flutter platform boilerplate is generated by the Flutter SDK:

```powershell
flutter create --platforms android,ios .
flutter pub get
flutter run
```

For Android emulator, `API_BASE_URL` defaults to `http://10.0.2.2:8000`. For a real phone, run the API with `--host 0.0.0.0` and use `flutter run --dart-define=API_BASE_URL=http://YOUR_COMPUTER_LAN_IP:8000`.

For a local HTTP demo on Android, add Internet permission and allow cleartext traffic in `android/app/src/main/AndroidManifest.xml`. Production deployment should use HTTPS.

The mobile UI is written in Dart widgets. Flutter does not use CSS; CSS is in the Electron desktop app.
